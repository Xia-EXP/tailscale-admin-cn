# 隐私与安全边界

## 不进入公开仓库的内容

以下内容属于运行时私密数据，发行版和 Git 历史都不应包含：

- data/config.json：API Token、OAuth Client Secret 和 tailnet 设置。
- data/access.json：后台账号的密码摘要和盐。
- data/remote-profiles.json：SSH 目标、用户名和私钥路径。
- data/fleet/identity/：Fleet 运维身份私钥。
- data/fleet/hosts/：known_hosts 和设备指纹。
- data/audit.log、设备清单、远程操作结果、诊断 JSON 和备份目录。
- ACCESS-URLS.txt：部署机器的域名和局域网地址。
- migration.enc.json：即使文件加密，也不应把某个 tailnet 的迁移包发布到公共仓库。
- runtime/：某台机器打包的 Node 二进制和运行时文件。

.gitignore 已覆盖上述目录和常见密钥文件，但提交前仍应检查 git diff --cached 和完整文件列表。

## 凭证保存方式

- API Token 和 OAuth Client Secret 只由服务端读取，浏览器只看到脱敏状态。
- 后台网页登录账号固定为 admin；密码只以加盐摘要保存，长度为 12–256 个字符。
- SSH 使用系统 OpenSSH，管理台不读取或保存私钥内容，也不保存 SSH 密码。
- 演示模式不会读取真实凭证，写操作只保存在内存中。

## 发布前检查

~~~powershell
git status --short
git diff --cached --name-only
rg -n -i 'tskey-|client.?secret|authorization:|BEGIN .*PRIVATE KEY|password\s*[:=]|192\.168\.|100\.(6[4-9]|[7-9]\d|1\d\d)\.' .
~~~

这些命令不能替代人工检查，尤其要检查新文件、压缩包、截图、日志和历史提交。

## 如果已经泄露

1. 立即在 Tailscale 管理后台吊销泄露的 API Token 或 OAuth Client。
2. 删除或轮换泄露的 SSH 私钥、后台密码和 webhook。
3. 清理 Git 历史后再推送，不能只删除当前工作树中的文件。
4. 检查审计日志和设备活动，确认没有异常操作。

## 网络边界

默认模式只监听 127.0.0.1。局域网安装会启用后台密码、Host 白名单和限制到局域网/Tailscale 网段的防火墙规则。不要把管理台端口直接转发到公网。
